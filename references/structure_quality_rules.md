# 结构质量判断规则

## AlphaFold / pLDDT

| pLDDT 范围 | 含义 | 建议 |
|---|---|---|
| > 90 | 高置信度 | 可用于详细分析、展示图、对接 |
| 70 — 90 | 骨架可靠 | 适合拓扑分析，侧链需谨慎 |
| 50 — 70 | 低置信度 | 仅用于大致折叠判断 |
| < 50 | 不可靠 / 无序 | 不要用于对接或突变分析 |

参考：Jumper et al., Nature 2021

## X 射线 / B-factor

| B-factor | 含义 |
|---|---|
| < 40 | 有序，质量好 |
| 40 — 80 | 中等柔性 |
| > 80 | 高度柔性 / 可能无序 |

## NMR

- B-factor 不适用于 NMR 结构
- 质量应查看 ensemble 中各模型的 RMSD
